# Generated bindings

The contents of this folder are **generated by CI** — do not edit by hand.

After the [`Generate bindings`](../.github/workflows/generate.yml) workflow runs,
this folder contains:

- `meshoptimizer.odin` — the Odin bindings (`package meshopt`)
- `meshopt_windows.lib` — static library for Windows (x64)
- `meshopt_linux.a` — static library for Linux (x64)
- `meshopt_macos.a` — universal static library for macOS (arm64 + x86_64)

Import it in your project by pointing an Odin collection or a relative import at
this folder. See the [top-level README](../README.md).
